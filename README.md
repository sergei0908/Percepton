# Перцептрон

Лабораторная работа 1 по Python, тема А1 «Перцептрон» (трек Data Science).

Однослойный перцептрон Розенблатта с пороговой активацией, написанный на numpy без
ML-библиотек. Модель обучается на синтетических облаках точек и на наборе iris,
умеет рисовать график ошибок по эпохам и границу решения.

## Как работает модель

Перцептрон считает взвешенную сумму признаков и сравнивает её с нулём:

```
z = w · x + b
ответ = 1, если z >= 0, иначе 0
```

Обучение идёт по правилу перцептрона: для каждого объекта

```
error = target - prediction      # 0, +1 или -1
w += learning_rate * error * x
b += learning_rate * error
```

Геометрически `w · x + b = 0` — это прямая (в общем случае гиперплоскость),
разделяющая классы. По теореме Новикова, если классы линейно разделимы,
перцептрон находит такую прямую за конечное число шагов. Если не разделимы —
не сходится никогда, поэтому число эпох ограничено.

## Установка

Нужен [uv](https://docs.astral.sh/uv/).

```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
uv sync
```

## Запуск

```bash
uv run python perceptron.py --samples 200 --lr 0.1 --epochs 50
```

```
Точек: 200, эпох пройдено: 2
Точность: 1.000
```

| Аргумент                   | По умолчанию | Что делает                                     |
|----------------------------|--------------|------------------------------------------------|
| `--samples`                | 200          | всего точек в двух облаках                     |
| `--lr`                     | 0.1          | скорость обучения                              |
| `--epochs`                 | 50           | максимум эпох                                  |
| `--spread`                 | 0.8          | разброс точек; больше 1 — облака перекрываются |
| `--seed`                   | случайный    | зерно генератора для воспроизводимости         |
| `--iris SPECIES [SPECIES]` | —            | обучить на iris вместо облаков                 |
| `--plots DIR`              | —            | сохранить графики в папку                      |

Неверные аргументы дают понятное сообщение и код выхода 2:

```
$ uv run python perceptron.py --samples abc
perceptron.py: error: argument --samples: ожидалось целое число, получено 'abc'
```

### Примеры

```bash
# графики: ошибки по эпохам и граница решения
uv run python perceptron.py --seed 0 --plots plots

# перекрывающиеся облака — модель не сходится
uv run python perceptron.py --spread 2.0 --seed 0 --plots plots

# iris: один вид против остальных
uv run python perceptron.py --iris setosa --epochs 100

# iris: два вида
uv run python perceptron.py --iris versicolor virginica --epochs 100 --plots plots
```

Для iris (4 признака) сохраняется только график ошибок: границу решения можно
нарисовать лишь для 2 признаков.

## Результаты на iris

100 эпох, `lr = 0.1`, обучение и оценка на всех объектах.

| Задача                      | Точность | Сошлась        |
|-----------------------------|----------|----------------|
| setosa против остальных     | 1.00     | да, за 4 эпохи |
| setosa против versicolor    | 1.00     | да, за 4 эпохи |
| virginica против остальных  | 0.98     | нет            |
| versicolor против virginica | 0.97     | нет            |
| versicolor против остальных | 0.44     | нет            |

- **Setosa** линейно отделима от остальных видов, поэтому перцептрон сходится
  и даёт 100%.
- **Versicolor и virginica** частично перекрываются: ошибки не доходят до нуля.
- **Versicolor против остальных** — худший случай: versicolor лежит между
  setosa и virginica, и одной гиперплоскостью её не отделить. Кроме того,
  перцептрон возвращает веса после последнего обновления, а не лучшие,
  поэтому на неразделимых данных итог может оказаться плохим. Улучшения:
  pocket-перцептрон (хранит лучшие веса) или многослойная сеть.
